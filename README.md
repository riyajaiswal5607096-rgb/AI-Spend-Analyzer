# AI Spend Analyzer 💸

A smart dashboard that helps users track AI tool expenses, analyze spending patterns, and discover cost-saving opportunities.

## Features
- Expense dashboard
- AI insights
- Pie chart analytics
- Tool management
- Efficiency score
- Export report
- Local storage support

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js
